# 000 平台端复刻 Demo 基线

## 基本信息

- 状态：已确认
- 提出日期：2026-06-10
- 最近更新：2026-06-15
- 对应 Demo：`demo/platform.html`
- 相关页面：首页、模型管理、标注、训练记录、图像库、客户端管理、用户中心

## 需求背景

为后续 1.4.2 新需求设计建立可操作的平台端原型基线，需要先理解并复刻现有 JetCheck 平台的主要页面、业务状态和核心交互。该 Demo 用于产品方案设计与验证，不作为生产系统的完整重建版本。

## 设计目标

1. 保留原平台主要信息架构和视觉语言。
2. 覆盖模型创建、标注、训练、测试等核心业务链路。
3. 覆盖图像库、客户端管理和账号信息等相关页面。
4. 提供可持续扩展的新版本原型基础。

## 设计范围

### 本次包含

1. 平台首页信息概览。
2. 模型列表、模型创建与编辑、训练记录。
3. 待训练、排队中、训练中、训练完成等状态。
4. 图像添加、矩形标注、标签、批量处理和开始训练。
5. 测试图像上传、测试结果和模型下载入口。
6. 图像库文件夹、图像列表、标签筛选、上传、详情和删除。
7. 客户端筛选、搜索与状态列表。
8. 用户中心和退出登录入口。

### 本次不包含

1. 真实后端接口和持久化数据库。
2. 真实模型训练、推理和文件传输。
3. 原系统所有边缘功能与像素级完全一致的视觉还原。
4. 生产环境权限、安全和资源调度实现。

## 设计结论

1. 当前复刻完成度可作为新需求设计基线，后续不再以逐项补齐原系统差异为优先目标。
2. 新需求直接在当前 Demo 上设计和实现。
3. 原系统仍作为行为和业务口径参考；新方案与原系统不同时，需要在对应需求记录中明确说明。
4. Demo 数据用于交互演示，可保存在浏览器本地存储中。

## 核心交互规则

1. 模型训练至少需要两张图像，并且全部完成标注。
2. 矩形标注在鼠标按下持续达到 20ms 后进入绘制，用于避免单击误建标注框。
3. 开始训练后自动进入训练记录页面。
4. 排队中的任务展示前方任务数量和预计等待时间，排到后自动进入训练。
5. 排队中和训练中的记录不能直接删除，必须先取消训练。
6. 训练完成后仍可查看和编辑标注。
7. 模型下载直接唤起浏览器下载，不增加站内下载进度。
8. 标注页刷新后恢复当前模型、训练记录和图像上下文。
