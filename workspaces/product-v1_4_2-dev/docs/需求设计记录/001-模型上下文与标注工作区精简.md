# 001 模型上下文与标注工作区精简

## 基本信息

- 状态：已确认
- 提出日期：2026-06-15
- 最近更新：2026-06-15
- 对应 Demo：`demo/platform.html`
- 相关页面：模型列表、训练记录、模型标注、模型测试

## 需求背景

原有模型相关页面沿用多级面包屑展示“模型管理 / 快捷模型 / 模型 / 版本 / 当前页面”。面包屑独占一行，但多数层级无法提供有效定位或跳转，压缩了列表和标注区域。标注页面还保留全局模型管理侧栏，进一步减少了核心画布空间。

## 设计目标

1. 减少重复、低价值的导航信息。
2. 在需要时清晰展示当前模型和训练版本。
3. 提升标注画布的可用面积。
4. 保持返回路径明确，不改变现有业务流程。

## 设计范围

### 本次包含

1. 移除模型相关页面的传统面包屑行。
2. 训练记录页展示当前模型。
3. 标注页展示当前模型和训练版本。
4. 标注页隐藏模型管理侧栏。
5. 压缩标注页顶部和内容区间距。

### 本次不包含

1. 调整平台顶部一级导航。
2. 修改模型、训练版本的数据结构。
3. 重构图像列表、标签面板和标注工具本身。
4. 改变模型测试的业务流程。

## 设计结论

1. “模型管理”“快捷模型”等固定层级不再作为面包屑重复展示。
2. 模型列表页直接以筛选区和列表作为页面主体。
3. 训练记录页在“返回”按钮右侧展示当前模型名称。
4. 标注页在“退出训练”按钮右侧展示当前模型名称和版本编号。
5. 模型测试等其他页面不展示模型路径面包屑。
6. 标注页隐藏左侧全局模型管理侧栏，主内容区域扩展至页面可用宽度。

## 页面与交互规则

### 页面结构

1. 训练记录页顶部左侧依次为：返回按钮、模型标签、模型名称。
2. 标注页顶部左侧依次为：退出训练按钮、模型标签、模型名称、分隔线、版本标签、版本编号。
3. 添加图像和开始训练仍位于标注页顶部右侧。
4. 标注页保留训练图像列表、画布和标签面板三部分。

### 操作流程

1. 点击训练记录页“返回”回到模型列表。
2. 点击标注页“退出训练”回到当前模型训练记录。
3. 模型名称和版本编号仅用于上下文识别，不提供点击跳转。

### 状态与反馈

1. 模型名称过长时单行省略，悬停可查看完整名称。
2. 页面切换后上下文信息随当前选中的模型和训练记录同步更新。
3. 标注页侧栏隐藏不影响顶部“模型管理”一级导航的选中状态。

### 校验与异常

1. 当前训练记录不存在时，继续沿用原逻辑返回训练记录页。
2. 当前模型名称或版本编号不新增额外空状态。

无数据和权限变化，仅调整信息呈现与页面布局。
