# 002 客户端采图模式改造

## 基本信息

- 状态：已确认，Demo 开发中
- 提出日期：2026-06-15
- 最近更新：2026-06-16
- 对应 Demo：`demo/client.html`
- 相关页面：检测工具启动、采图运行页、工具采图记录

## 需求背景

客户端当前将采图作为检测工具的一种运行模式。原流程缺少常驻相机画面、分图像数量统计、单图标签和采图图像管理，难以支撑连续采图与多相机采图作业。

需要解决：

1. 采图时持续查看当前相机画面，确认产品是否放置到位。
2. 分别查看各图像获取项已经采集的数量。
3. 支持多个图像获取项同时展示相机画面，并由用户按需独立触发。
4. 每次采图前为对应图像获取项选择标签，采集时自动写入该图像。
5. 按工具汇聚全部采图图像，并支持跨时间相册批量导出、删除、改标签和同步到云端。

## 业务概念

### 采图批次

用户从开始采图到点击结束采图之间产生的一组图像。提前结束也表示该批次正式结束，采图记录仅保留实际采集数量，不区分“完成”与“未完成”，结束后不能继续追加。

### 图像获取项

检测工具中已有的图像来源配置，例如产品正面相机、侧面相机，或同一移动相机的不同点位。

### 本次采集配置

采图批次不区分“轮流采集”或“同时采集”模式，也不引入“采集组”概念。

1. 进入采图模式时直接开始，不展示初始配置弹窗。
2. 全部图像获取项默认开启，需要调整时再进入“采图设置”。
3. “采图设置”仅控制本次是否采集某个图像获取项，不再设置目标数量。
4. 运行页同时展示全部已开启项目的实时画面，每个画面有独立采集按钮，由用户自行决定触发顺序和时机。

### IO 配置

IO 是外部按钮每次按下时触发何种动作的配置，与运行页上的手动操作是两套入口。

1. “触发下一个采图”和“依次触发全部采图”仍按 IO 配置执行。
2. 指定图像获取项的 IO 动作只触发对应项目。
3. IO 行为不决定运行页的界面模式，运行页始终由用户独立触发各画面采集。

## 设计方案

### 1. 开始采图

选择采图模式后直接进入运行页：

1. 全部图像获取项默认开启。
2. 有需要时再通过运行页“采图设置”调整。
3. 设置中使用“采集 / 不采集”开关表达本批次是否启用该项。
4. 不再展示目标数量字段，避免让用户误以为系统会自动停止或强制补齐。

### 2. 采图运行页

运行页取消原来的批次摘要行，左上角保留返回工具列表入口，点击左侧“检测工具”菜单也回到检测工具列表，顶部原“退出工具”按钮改为“结束采图”。

#### 左侧：图像列表

左侧保持较窄宽度，把主要空间留给实时相机画面。每个图像获取项独立展示：

1. 图像名称。
2. 实际已采数量。
3. 最近 6 张采集图像缩略图，按 3 列 2 行展示，保持图片比例不挤压。
4. “查看全部图像”入口。

点击图像标题或缩略图后，右侧详情区域切换到对应图像。

#### 右侧：实时相机画面

1. 以网格同时展示全部已开启图像获取项对应的相机画面。
2. 一路画面占满区域；两路画面并列并尽量撑满可用空间；三路及以上采用两列网格并允许纵向滚动。
3. 每个画面提供独立、加宽的“采集”按钮，不设置全局采集模式或全局采集按钮。
4. 每个相机画面支持鼠标滚轮缩放和拖拽平移，底部保留弱化的缩放工具条。
5. 相机画面容器使用白底，减少深色空白区域对图像观察的干扰。
6. 不展示图像获取项数量、相机连接路数等冗余统计。
7. 左侧图像名称下不重复展示相机和参数组。

#### 每个画面：采图标签

1. 每个相机画面下方展示该图像获取项的可选标签，默认提供 `OK`、`NG`。
2. 默认使用单选标签；可在标签设置中切换为多选标签。
3. 每个图像获取项记住上一次使用的标签，下次采图自动选中。
4. 标签右侧提供设置入口，可在弹窗中增删该图像获取项的可选标签，并配置单选/多选方式。
5. 单个标签最多 8 个字符，每个图像获取项最多配置 3 个可选标签。
6. 标签控制区使用白底，与相机画面明确分区。
7. 运行主界面不提供导出和删除入口，避免操作区过重。

### 3. 提前结束

1. 点击“结束采图”后提示当前实际采集数量。
2. 用户确认后，本批次直接结束并进入工具采图记录。
3. 不标记“未完成”，也不提供继续采集入口。
4. 批次标题仅显示实际采集张数。

### 4. 工具采图记录弹窗

从运行页各图像项或工具卡片的采图记录入口进入。

1. 左侧保留图像获取项列表，并显示该项在全部历史采集中的图像总数。
2. 中间仅展示当前图像获取项的历史图像，按采集开始时间形成可折叠时间相册，不显示批次编号和状态。
3. 图像数量为 0 的历史相册不显示；全部相册都允许折叠，不强制保留一个展开项。
4. 缩略图一行至少展示 5 张；选择状态覆盖在左上角，标签覆盖在左下角，点击图像任意区域均可选中。
5. 支持按标签筛选当前图像列表，包含全部标签、未标注和已有标签。
6. 支持逐张、Shift 连选、整相册和当前图像获取项内全选；筛选切换时清空选择，避免隐藏图像被误操作。
7. 时间相册展开折叠使用图标化箭头，展开时旋转并高亮。
8. 右侧查看当前图像大图、图像获取项、文件名、采集时间、图像尺寸、采集设备和标签。
9. 图像大图支持鼠标滚轮缩放和拖拽平移，缩放工具条底部居中放置；右侧详情列适当加宽，避免字段拥挤。
10. 单图标签在“标签”行右侧固定展示编辑图标按钮，不使用大按钮；标签完整显示，不做省略截断。
11. 单张图像最多包含 3 个标签；批量修改标签使用气泡弹窗输入，多个标签可用分号分隔。
12. 支持所选图像批量导出、删除和同步到云端。
13. 删除按钮显示当前数量，例如“删除所选（5）”。
14. 底部操作中，“导出”为次按钮，“同步到云端”为主按钮。

### 5. 同步到云端

1. “同步到云端”仅客户端在线时可用。
2. 用户可选择平台端图像库已有文件夹，或输入名称新建文件夹。
3. 同步后图像保留采集时间、文件名和全部标签。
4. 平台 Demo 已有本地数据时直接写入图像库；平台缓存尚未初始化时先写入待同步队列，平台打开后自动合并。

### 6. 记录归属

1. 检测记录页面不再显示采图批次，也不提供“采图模式”筛选。
2. 采图批次统一归属于对应工具的采图记录。
3. 工具卡片提供采图记录入口，运行页“查看全部图像”进入同一入口。
