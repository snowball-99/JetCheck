## 文件地图

### `docs/`（1.5 设计文档）

1. `需求设计记录/README.md`：需求索引、状态与记录规则
2. `需求设计记录/TEMPLATE.md`：单项需求记录模板
3. `需求设计记录/000-008`：平台端基线、客户端采图与运行、尺寸工具、交互反馈和默认示例数据等需求记录

5. `捷检1.4.2客户端异常清单.md`：1.5 前客户端交互对齐使用的异常口径参考

### `demo/`（当前原型基线）

1. `dimension-tool.html` + `dimension-tool.js`：独立本地尺寸工具雏形（工程工作台骨架）
2. `client.html` + `client.js`：客户端原型（运行态与记录）
3. `platform.html` + `platform-replica.js` + `platform-replica.css`：平台端复刻原型
4. `shared.js`：客户端/平台端共享状态和工具函数
5. `styles.css`：共享样式
