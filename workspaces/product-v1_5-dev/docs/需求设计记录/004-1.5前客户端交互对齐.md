# 004 1.5 前客户端交互对齐

## 基本信息

- 状态：已确认，Demo 已实现
- 提出日期：2026-06-29
- 最近更新：2026-06-29
- 对应 Demo：`demo/client.html`、`demo/dimension-tool.html`
- 相关页面：客户端检测工具、检测运行页、检测记录、相机管理、IO模块管理、工具配置、模型选择抽屉、尺寸工具

## 需求背景

在 1.5 正式开始前，需要先对齐一批 1.4.2 小版本中已经明确的客户端交互问题，避免后续采图模式和检测流程设计建立在过时的原型状态上。

本批需求以小范围交互补齐为主，不引入新的业务主流程。

## 设计目标

1. 补齐检测运行中各采图项的状态反馈，让用户能分辨待检测、检测中、OK、NG 和异常。
2. 异常结果在周期结果、检测记录和详情中保持一致，并能查看异常信息。
3. 减少配置过程中的页面跳转和重复输入。
4. 提升工具、IO模块、模型选择和尺寸工具的常用操作效率。
5. 保持与 1.4.2 异常清单和已有客户端配置规则一致。

## 设计范围

### 本次包含

1. 相机参数组字段顺序调整。
2. 检测运行页采图项状态条与异常 hover 信息。
3. 检测记录异常结果与异常汇总展示。
4. 常用弹窗回车确认。
5. 尺寸工具默认 ROI 调整为全图范围。
6. 连续触发防错提示。
7. 检测工具复制。
8. IO模块工具并行配置。
9. 模型选择抽屉增加导入模型入口。

### 本次不包含

1. 真实相机、模型服务和 IO 硬件接口联调。
2. 异常清单以外的完整错误码覆盖。
3. 检测算法结果的真实推理逻辑。
4. 1.5 采图模式主方案重构。

## 设计结论

1. 相机参数组按“名称、自动曝光、曝光时间、自动增益、增益时间、宽、高、X偏移、Y偏移”排序。
2. 检测运行页每个采图项左侧增加状态条，状态包括：`待检测`、`检测中`、`OK`、`NG`、`异常`。
3. 采图项异常时显示红色状态条和感叹号，hover 展示对应异常文案。
4. 任一采图项异常时，本周期总结果为 `异常`；检测记录列表、详情和图像结果均展示 `异常`，并在右侧显示感叹号查看异常汇总。
5. 弹窗内按 Enter 触发确认，但文本域和组合输入场景不抢占输入。
6. 尺寸工具默认 ROI 蓝框覆盖全图范围。
7. 当前周期未结束且触发会跨周期时，拒绝触发并提示：“检测中，请勿重复触发”。
8. 工具列表支持复制工具，默认名称为“原工具名 副本”。
9. IO模块新增“工具并行”开关，默认关闭；关闭时同一 IO 模块关联工具仅允许一个运行，开启后允许多个关联工具同时启动和触发。
10. 工具配置选择模型时，模型抽屉提供“从云端下载”和“导入本地模型”两个入口，避免离开当前配置页面。

## 页面与交互规则

### 页面结构

1. 检测运行页采图项卡片左侧增加竖向状态条，右侧保留图像名称、输入源和查看按钮。
2. 检测记录列表的结果列支持 `异常` 筛选与异常角标。
3. IO模块管理列表新增“工具并行”列，新增/编辑弹窗中增加同名开关。
4. 模型选择抽屉顶部操作区增加模型导入入口。

### 操作流程

1. 用户复制工具时，点击工具卡片操作区的复制图标，输入工具名称后确认创建。
2. 用户配置 IO 模块时，可开启或关闭工具并行；关闭时若已有同模块工具运行，再启动其他关联工具会被拦截。
3. 用户选择模型但本地无目标模型时，可直接在抽屉中下载云端模型或导入本地模型，完成后继续选择。
4. 用户在确认弹窗中按 Enter，可直接提交确认操作。

### 状态与反馈

1. 采图项待运行显示灰色 `待检测`。
2. 周期执行中显示蓝色 `检测中`。
3. 结果为 OK 显示绿色 `OK`。
4. 结果为 NG 显示红色 `NG`。
5. 异常显示红色 `异常`，并带感叹号 hover 说明。
6. 连续触发被拦截时显示：“检测中，请勿重复触发”。

### 校验与异常

1. 异常文案以 `docs/捷检1.4.2客户端异常清单.md` 为准。
2. Demo 中模拟覆盖相机未连接、相机参数冲突、模型不存在、模型推理异常等典型情况。
3. 工具复制名称不能为空，确认后生成独立工具、采图项、处理项、检测项与 IO 配置副本。
4. IO模块默认不允许工具并行，避免多个工具同时占用同一模块导致触发混乱。

## 数据与权限影响

1. IO模块数据新增 `parallel` 字段，旧数据未设置时按 `false` 处理。
2. 工具复制会生成新的工具 ID 和内部节点 ID，不复用原工具运行状态。
3. 检测记录新增异常信息字段，用于列表与详情展示。
4. 模型导入仍进入本地模型列表，不改变模型权限规则。
