# 005 尺寸工具构造元素常驻列表

## 基本信息

- 状态：设计中，Demo 已实现
- 提出日期：2026-07-02
- 最近更新：2026-07-02
- 对应 Demo：`demo/dimension-tool.html`
- 相关页面：尺寸工具测量项配置、尺寸工具标定、尺寸工具画布

## 需求背景

尺寸工具中使用“线线交点”构造点时，如果参与构造的两条直线近似平行，计算出的交点可能位于图像边界之外。当前交点不在画布可见范围内，用户无法直接点击选中，也感知不到构造异常，更无法删除该构造元素。

该问题会导致工程中存在不可见、不可选、不可删除的异常元素，影响后续测量项配置和发布可信度。

## 设计目标

1. 所有已创建元素、构造元素、测量项都应有稳定的列表入口，不依赖画布可见性。
2. 构造失败或构造结果超出图像边界时，用户能明确感知异常状态和原因。
3. 用户可以从列表中选中、定位、删除异常元素。
4. 后续测量项引用异常元素时，应能提示依赖异常，避免静默发布错误模板。

## 设计范围

### 本次包含

1. 在尺寸工具测量项配置区域增加左侧常驻元素列表。
2. 元素列表显示元素名称、类型、状态和操作。
3. 异常元素在列表中高亮展示，并在元素信息中显示异常原因。
4. 列表支持选中、定位和删除。
5. Demo 中模拟“近似平行线线交点超出图像边界”的异常元素。

### 本次不包含

1. 真实几何求交算法调整。
2. 真实工程文件的数据结构迁移。
3. 所有构造工具的完整异常枚举。
4. 画布无限扩展或图像外坐标可视化能力。

## 设计结论

1. 尺寸工具左侧增加常驻“元素列表”面板，与工具箱放在同一侧。
2. 元素列表至少展示：
   - 元素名称。
   - 元素分类：元素、构造、测量。
   - 元素类型：直线段、点、线线交点等。
   - 状态：有效、异常。
   - 操作：定位、删除。
3. 当构造结果位于图像外时，不应因为画布不可点击而丢失管理入口，应在元素列表中保留该元素并标记为异常。
4. 点击异常元素后，右侧元素信息显示异常说明，例如“交点超出图像边界，无法在画布中直接点击。请在元素列表中定位或删除。”
5. 点击“定位”时：
   - 图像内元素：画布聚焦或选中该元素。
   - 图像外元素：提示该元素超出图像边界，并保持列表选中。
6. 点击“删除”时，删除该元素及其下游依赖关系。若存在下游引用，正式实现需二次确认。
7. 测量项本质也是输出元素的一种，应并入元素列表统一管理，不再作为完全独立的列表概念。

## 页面与交互规则

### 页面结构

1. 左侧侧栏顺序建议为：工具箱、元素列表。
2. 右侧侧栏展示当前选中元素的信息、参数和测量值。
3. 元素列表在测量项配置页常驻显示。
4. 手动标定场景如允许创建元素，也应显示工具箱和元素列表。

### 操作流程

1. 用户创建或构造元素。
2. 系统将元素写入元素列表。
3. 若构造结果正常，状态为“有效”。
4. 若构造结果超出图像边界、无解或依赖元素异常，状态为“异常”。
5. 用户可从元素列表选中该元素，查看详细信息。
6. 用户可定位或删除元素。

### 状态与反馈

1. 有效元素使用普通状态。
2. 异常元素使用红色或警示状态。
3. 异常信息应展示可读原因，不只显示“失败”。
4. 删除后元素从列表移除，画布和依赖关系同步更新。

### 校验与异常

1. 构造点坐标超出图像范围时，元素状态为异常。
2. 两条直线近似平行导致交点距离过远时，元素状态为异常。
3. 上游元素被删除时，下游构造元素应同步删除或标记依赖缺失。
4. 发布前检查应拦截仍存在异常状态的元素。

## 数据与权限影响

1. 工程数据中需要保存元素列表及状态。
2. 元素应具有稳定 ID，用于列表、画布、测量项引用和依赖关系维护。
3. 异常状态需要保存异常码或异常原因，便于重新打开工程时恢复。
4. 删除元素时需处理下游依赖，避免残留无效引用。

3. 发布前检查中，异常元素是否一律阻断发布。
