# 008 齿轮主场景默认示例数据

## 基本信息

- 状态：设计中，Demo 已实现
- 提出日期：2026-07-10
- 最近更新：2026-07-13
- 对应 Demo：`demo/client.html`
- 相关页面：客户端检测工具、相机管理、IO模块管理、检测记录、采图记录

## 需求背景

1.5 版本以齿轮项目作为主项目场景。Demo 打开后如果仍以安全座椅作为首个工具，运行页、检测记录和 IO 配置无法自然支撑齿轮场景讨论。

因此需要在默认数据中提供齿轮项目的完整业务样例，让测试和设计评审可以直接围绕齿轮流程展开。

## 默认数据范围

1. 本地模型：
   - 示例-齿轮齿面识别，目标检测模型，类别为“齿面”。
   - 示例-齿轮气泡检测，缺陷检测模型，底层等价于单类别目标检测。
2. 相机：
   - 齿轮A相机。
   - 齿轮B相机。
3. IO模块：
   - 齿轮转盘IO，型号 USR-IO808。
   - DI1 至 DI6 分别对应按钮/0°到位、30°到位、60°到位、90°到位、120°到位、150°到位。
   - DO1/DO2/DO3 分别对应 NG、OK、异常三色灯。
4. 检测工具：
   - 工具名称“齿轮”。
   - 图像获取项为 A/B 两相机在 0°、30°、60°、90°、120°、150° 的 12 个采图项。
   - 图像处理为每个采图项进行齿面识别。
   - 图像检测统一使用齿轮气泡检测模型。
5. 记录数据：
   - 默认检测记录中新增 3 条齿轮记录，包含 OK 与 NG 样例。
   - 默认采图记录中新增 1 条齿轮采图记录，便于查看采图记录弹窗与批量操作。

## 设计结论

1. 齿轮工具排在默认工具列表第一位，进入客户端 Demo 后优先看到齿轮项目。
2. 齿轮检测记录排在默认检测记录前面，运行页最近结果优先展示齿轮检测项。
3. 所有默认示例工具、相机、模型、IO 以及相关默认记录的展示名称统一增加“示例-”前缀，用于和用户自行创建的数据区分。
4. 对已有浏览器缓存增加版本迁移：当旧缓存版本低于 19 时自动补齐齿轮模型、相机、IO、工具、检测记录和采图记录；低于 20 时自动为默认示例数据补齐“示例-”前缀。
5. 齿轮采图项默认使用 `sample-images/齿轮.jpg`，已有旧缓存会在版本 21 迁移时同步替换默认齿轮示例图像路径。
6. 齿面识别在每张整图中输出 5 个齿面区域，标签只显示“齿面”，不显示序号。
7. 气泡检测在齿面识别裁剪出的子图上执行，结果需要映射回整图中的齿面区域内展示。
8. 齿轮检测周期结果由所有整图结果汇聚而成；整图结果由其下齿面子图结果汇聚而成，默认全 OK 才 OK，有任一 NG 则 NG，有异常则异常。

## 待确认项

1. 是否需要补充真实齿轮项目图像素材，替换当前占位样例图。
2. 齿轮检测项是否需要按角度分组展示，而不是完全平铺。
3. 齿轮场景默认异常记录是否需要覆盖相机超时、IO重复触发等异常类型。
