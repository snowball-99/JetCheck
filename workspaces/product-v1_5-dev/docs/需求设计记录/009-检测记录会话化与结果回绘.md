# 009 检测记录会话化与结果回绘

## 基本信息

- 状态：设计中，Demo 已实现
- 提出日期：2026-07-12
- 最近更新：2026-07-21
- 对应 Demo：`demo/client.html`
- 相关页面：客户端检测运行页、检测记录、检测记录抽屉、图像结果详情

## 需求背景

检测记录原先按每一次检测触发生成独立记录，用户查看时会在“记录列表 -> 会话详情 -> 图像详情”之间多层跳转。对于齿轮这类一个周期包含多个采图项、多个角度和多相机结果的场景，这种结构会让用户难以理解当前看到的是一次触发、一个完整周期，还是整段运行会话。

同时，齿轮和背板的检测结果如果只在详情里显示，而主检测界面只显示 OK/NG 总结果，用户会困惑：为什么某项已经 NG，但主图上看不到任何检测框或缺陷位置。

## 关键定义

1. 检测会话：用户进入某个检测工具并运行，到结束检测前形成的一段记录汇总。
2. 检测记录：一次完整检测周期的记录。一个周期包含该工具配置下所有应触发的图像获取项。
3. 未完成记录：当前周期尚未完成时形成的临时展示状态，只用于运行页和当前会话抽屉，不进入完整统计口径。
4. 子图/分区：由图像处理步骤从整图中识别或裁剪得到的区域。齿轮场景中，齿面识别会从整图中识别出多个齿面区域；背板全图处理不产生独立子图概念。

## 设计目标

1. 检测记录按“会话 -> 记录”组织，而不是按单次图像项触发孤立展示。
2. 当前运行页的“查看全部”和检测记录列表的“查看详情”使用同一套抽屉结构，减少二次弹窗。
3. 记录抽屉中直接展示记录列表和选中记录的所有图像结果，不再一层套一层。
4. 检测结果需要回绘到主图，主界面、记录抽屉和图像详情保持一致。
5. 齿轮和背板结果展示要符合真实业务逻辑：齿轮先识别齿面再检测气泡，背板缺陷直接绘制在原图。
6. 用户在检测记录中需要快速筛选 OK、NG、异常和未完成记录，并能连续查看图像结果。

## 设计范围

### 本次包含

1. 检测记录从独立条目调整为会话汇总展示。
2. 检测运行页右侧“最近记录”和“查看全部”接入当前会话抽屉。
3. 检测记录列表进入详情后使用右侧抽屉样式，标题为“会话编号 · 检测记录”。
4. 抽屉左侧为记录列表，右侧为选中记录的图像结果网格。
5. 记录列表支持按结果快速筛选。
6. 主检测卡片、记录抽屉图像卡片和图像详情统一显示检测框。
7. 齿轮检测框：整图显示齿面识别框，齿面内部显示气泡缺陷框。
8. 背板检测框：全图处理不显示“全图子图框”，缺陷结果直接绘制在原图上。
9. 图像详情支持左右方向键切换图像，优先支持跨记录连续浏览。

### 本次不包含

1. 后端真实会话持久化和跨设备记录同步。
2. 真实算法框坐标解析和图像标定坐标换算。
3. 长周期生产统计、班次报表和质量趋势分析。
4. 检测记录导出格式重新设计。

## 设计结论

1. 检测记录列表展示会话级记录，编号使用 `RUN-YYYYMMDD-HHMMSS`，避免随机长串 ID。
2. 会话详情不再使用居中大弹窗，统一使用右侧抽屉；抽屉标题显示 `RUN-YYYYMMDD-HHMMSS · 检测记录`。
3. 抽屉内不再显示顶部会话汇总条，避免重复占用空间。
4. 左侧标题为“记录列表”，每条记录以检测记录编号作为主标题，时间和节拍作为副信息。
5. 检测记录编号使用 `REC-YYYYMMDD-序号`，其中序号为当前会话内递增编号。
6. 时间显示完整年月日与时分秒；节拍使用更接近现场阅读的短格式，例如 `9s`、`1m 12s`。
7. 右侧显示当前记录的所有图像结果，图像卡片布局和运行页检测项卡片一致。
8. 未完成周期只显示已触发图像项的结果，未触发图像项显示待检测，不得回退显示示例图或伪造 OK 结果。
9. 点击最近记录时，不再打开旧会话详情弹窗，而是打开右侧抽屉并定位到该记录。
10. 点击抽屉图像卡片时，打开统一的整图结果详情弹窗。
11. 记录列表顶部提供“全部 / OK / NG / 异常 / 未完成”快速筛选，并显示各状态数量。
12. 记录列表超过单页可视数量时使用分页，不依赖长列表滚动；筛选切换后回到第一页。
13. 抽屉中的记录列表和图像结果区需要撑满抽屉可用高度，避免随内容高度变化造成布局不稳定；检测运行页和检测记录页进入的抽屉应使用同一布局规则。
14. 齿轮整图显示齿面识别框，标签只显示模型类别“齿面”，不显示“齿面1/齿面2”等序号。
15. 齿轮气泡缺陷检测结果需要映射回齿面所在整图位置，NG 框和标签为红色，OK 框和标签为绿色。
16. 背板全图检测不显示“1 个子图”或全图 ROI 框，缺陷框直接绘制在原图缺陷位置。
17. 主检测界面和检测记录抽屉都需要回绘检测结果，否则用户只能看到 NG 标记，看不到 NG 原因。
18. 检测运行页进入后隐藏左侧主菜单，保留顶部返回入口与工具信息，优先把横向空间让给检测项画面。
19. 客户端顶栏与左侧菜单整体压缩为更紧凑规格，非运行页仍保留导航入口，运行页自动进入专注检测布局。
20. 检测运行页右侧信息栏不再显示“本次结果”和“本次节拍”，中部留给最近记录，底部固定操作按钮。

## 页面与交互规则

### 检测运行页

1. 主区域检测项卡片在检测完成后显示图像、总结果和回绘后的结果框。
2. 齿轮卡片显示齿面识别框；若某个齿面 NG，则在对应齿面内显示缺陷框。
3. 背板卡片直接显示缺陷检测框。
4. 进入检测运行页时隐藏左侧菜单栏，并将内容区改为单列铺满；顶部栏保持紧凑显示，返回工具列表或切换其他页面后恢复左侧菜单。
5. 右侧栏操作区固定在底部，重置按钮在上、检测按钮在下，检测按钮保持主按钮样式。
4. 点击卡片打开整图详情。

### 检测记录抽屉

1. 左侧记录列表展示当前会话内的完整记录，最近记录在上。
2. 右侧默认展示选中记录的所有图像结果。
3. 图像卡片不展示“5 个子图/分区”等说明，避免遮挡底部名称。
4. 未完成图像项显示“待检测”，不显示示例图。
5. 超出抽屉可视区域时，右侧图像区可滚动；左侧记录列表保持可选。

### 图像详情

1. 详情标题只显示图像名称。
2. 齿轮详情为单整图画布，支持缩放；齿面区域内直接显示气泡检测结果框。
3. 点击齿面或缺陷区域时，自动缩放到该识别框适合查看的范围。
4. 背板详情只显示原图和缺陷框，不显示子图数量、全图框或全图子图标签。
5. 详情标题栏不显示“子图数量”，改为显示所有类别数量，包括图像处理识别类别和子图检测类别，例如齿轮场景显示 `齿面：5`、`缺陷：1`。
6. 详情弹窗去掉底部“关闭”按钮，只保留右上角关闭入口；按 `Esc` 也可关闭。
7. 详情弹窗支持左右方向键切换图像；从检测记录进入时，可跨当前会话内不同记录的图像连续切换。

## 数据与权限影响

1. Demo 使用本地 `sessionId` 将检测记录归并到运行会话。
2. 完整周期结束后才进入检测数量、良品率、OK/NG/异常统计。
3. 未完成周期只作为当前 UI 状态展示，不参与历史会话统计。
4. 真实产品需要后端或客户端运行服务提供稳定会话 ID、周期编号、开始/结束时间和检测框坐标。

- 实现状态：已完成轻量原型
- 验证结果：
  1. 检测运行页“查看全部”和最近记录均可打开右侧记录抽屉。
  2. 检测记录列表详情已改为右侧抽屉样式。
  3. 未完成周期不会生成多条伪记录，未触发图像项不再回退显示示例图。
  4. 齿轮主图已显示齿面识别框，缺陷框可回绘到齿面所在整图位置。
  5. 背板全图检测已去掉全图 ROI 框，缺陷框直接绘制在原图上。
  6. 记录列表已支持按结果快速筛选。
  7. 图像详情已支持左右方向键跨记录切换图像，并移除底部关闭按钮。
  8. 记录抽屉两栏已撑满可用高度，记录列表超过 8 条后显示分页；少量图像时图像卡片自动分配剩余空间，避免底部出现明显空白。

  1. 检测框坐标为 Demo 模拟坐标，不代表真实模型输出。
  2. 图像详情缩放为前端示意交互，真实产品需结合实际图像查看组件。

## 待确认项

1. 检测记录编号是否最终采用 `REC-YYYYMMDD-序号`，还是需要包含工具/产线/班次信息。
2. 记录抽屉是否需要支持按 OK/NG/异常快速筛选当前会话记录。
3. 检测结果框是否需要支持显示置信度阈值、模型名称或检测项名称。
