# 015 客户端算子数据回流

## 基本信息

- 状态：设计中，Demo 已实现
- 提出日期：2026-07-22
- 最近更新：2026-07-22
- 对应 Demo：`demo/client.html`
- 相关页面：客户端检测记录页、检测记录抽屉、平台端算子实例与数据优化流程

## 需求背景

客户端在真实项目中会持续产生现场图像与算子推理结果，这些数据是后续优化平台端算子的关键来源。检测记录更多服务于现场追溯，记录的是工具运行后的业务结果；但算子优化需要的是某个算子实例的输入与输出，而不是客户端规则计算出的 OK/NG 判定。

在 013 平台端算子实例架构口径下，一个检测工具可能同时包含图像处理算子和图像检测算子。因此数据回流必须支持按算子归集，并支持跨会话批量选择后统一回流。

## 设计目标

1. 支持从客户端检测记录页批量发起数据回流。
2. 回流对象按算子去重归集，能覆盖同一算子在不同工具、不同处理实例或检测实例中的数据。
3. 回流内容包含算子输入图像和算子推理结果。
4. 不回流客户端业务规则产生的检测结果，避免将工具判定规则误当作算子标签。
5. 支持跨会话选择后汇总展示涉及的算子和数据量。
6. 弹窗直接展示所有涉及算子，不在回流前要求用户再次选择算子范围。

## 设计范围

### 本次包含

1. 检测记录页右上角批量操作区增加“批量数据回流”入口。
2. 用户勾选一条或多条检测会话后，可以发起数据回流。
3. 回流弹窗直接展示已选记录涉及的所有算子。
4. 回流预览先按算子展示输入图像总数和推理结果总数，再折叠展开查看每个工具实例下的数量。
5. 推理结果数量指每张输入图像或子图对应的一份推理结果矢量，不按检测框数量累计。
6. Demo 中将逐张输入和推理结果写入回流队列，并由平台端真实消费到图像库或算子样本池。

### 本次不包含

1. 自动回流策略。
2. 真实服务端 HTTP 上传接口；当前 Demo 通过共享浏览器存储模拟跨端传输。
3. 回流数据审核、清洗、去重和标注任务分发。
4. 平台端训练集自动合并。
5. 大文件分片上传、断点续传、传输失败重试等工程细节。

## 设计结论

1. 回流入口放在检测记录页批量操作区，而不是单条记录详情内。
2. 回流数据不以客户端最终检测结果为核心，而以去重后的算子为核心。
3. 图像处理算子的回流输入是原始图像，推理输出是处理阶段识别出的区域、类别、置信度等结果。
4. 图像检测算子的回流输入是它实际消费的图像。如果检测算子关联图像处理输出，则处理后的子图或全图处理结果作为检测算子输入。
5. 每个处理实例或检测实例都可以先以空壳存在。没有关联平台算子时只显示输入，不产生推理结果，也不能自动进入算子样本池。
6. 推理结果数量不是检测框数量，而是算子对某张图像或子图完成推理后产生的一份结果矢量；如果算子为空壳，可只有输入图像而没有推理结果。
7. 客户端规则判定结果仅保留在检测记录中，不进入算子数据回流包。
8. 弹窗不提供算子范围筛选，避免用户误以为回流目标是某个旧算子版本；真实回流对象始终是算子实例。
9. 未关联平台算子的实例由本次人工操作把输入图像回流至平台图像库；平台不会猜测其算子归属。
10. 已关联平台算子的实例按 `operatorId` 回流至目标算子样本池。
11. 检测算子的输入为处理后的子图或全图处理结果，回流包不额外携带原始整图。
12. 目标算子没有可编辑草稿版本时，平台在首次接收回流数据时自动创建下一草稿版本，使新样本可以立即进入标注流程；已发布版本保持冻结。
13. 平台图像库保留“文件夹 → 图像”两层结构。未关联算子的人工回流统一进入“客户端未关联算子数据”文件夹，图像库根页面不直接平铺图像。
14. 新建处理或检测实例时，未选择算子的选择框保持空白且不阻止创建；创建后的实例摘要统一回显“算子未关联”。空壳处理实例允许运行，但只保留输入、不产生算子输出。

## 交互规则

### 入口

1. 进入客户端“检测记录”页面。
2. 勾选一条或多条检测会话记录。
3. 点击右上角“批量数据回流”。

### 回流弹窗

1. 弹窗中直接显示已选记录涉及的所有算子，同一算子只显示一次。
2. 算子列表中显示：
   - 算子名称。
   - 所属阶段：图像处理或图像检测。
   - 算子类型。
   - 输入图像总数。
   - 推理结果总数。
   - 可展开的实例明细，格式为“检测工具 / 图像项”，并显示该实例下的输入图像数量和推理结果数量。
3. 算子名称只展示算子名，不展示旧算子版本号，避免把数据回流理解为回流到某个版本。
4. 未关联平台算子的实例显示“仅回流输入图像至图像库”；已关联实例显示“回流至算子样本池”。

### 提交反馈

1. 点击“确认回流”后，已关联实例进入算子数据回流队列，未关联实例的输入进入图像库同步队列。
2. 在线状态下显示加入成功。
3. 离线状态下仍允许加入队列，后续可由真实实现补充待上传状态。
4. 无可回流算子数据时禁用确认按钮。
5. 浏览器本地缓存不足时提示保存失败。

## 数据口径

### 回流数据包含

1. 会话 ID、检测记录 ID。
2. `operatorId`、`weightId`、`deploymentId`、`configRevision`、算子名称、算子类型和所属阶段。
3. 每张算子输入资产的名称、地址、尺寸、输入类型和采集时间。
4. 每张输入对应的推理输出、输出类别、缺陷框或识别框信息。
5. 每个算子在不同图像来源下的输入图像数量和推理结果数量。
6. 回流任务创建时间和队列状态。

### 回流数据不包含

1. 客户端判定规则配置。
2. 客户端汇总后的周期 OK/NG/异常结果。
3. 三色灯、IO 输出等现场执行结果。
4. 用户现场操作过程中的临时 UI 状态。

## Demo 实现记录

- 实现状态：已实现客户端到平台端的真实 Demo 数据流
- 实现入口：检测记录页右上角“批量数据回流”
- 队列位置：浏览器本地 `jetcheck-client-data-return-v1`
- 验证结果：已验证已关联算子回流后自动进入算子草稿版本；已验证未关联实例只回流输入且推理结果为 0
- 已知差异：
  1. 当前通过浏览器共享存储模拟传输，没有真实网络接口和文件上传。
  2. 回流队列暂无独立管理页面。
  3. 处理后子图在 Demo 中复用展示资源并携带裁剪区域；正式实现应上传真实子图文件。

## 待确认项

1. 回流数据是否需要支持人工备注、现场批次号、产品型号等额外上下文字段。
2. 后续是否需要按算子配置默认回流策略。
